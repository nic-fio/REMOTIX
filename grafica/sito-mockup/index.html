How it works

One server, one web page. Nothing else.

REMOTIX runs on your Linux server and serves its own page. Whoever connects needs only a modern browser: Windows, macOS, Linux, Android, ChromeOS.

A real desktop per user

GNOME, KDE Plasma, XFCE or LXQt. Each user gets their own session on the same server, isolated from the others.

It waits for you

Close the browser, change device, come back tomorrow: the session keeps running and your windows are still there.

Fast on a modest server

The graphics card compresses the screen in H.264, and the browser decodes it in hardware. Video, audio and clipboard included.

Why REMOTIX

Built for Linux, not adapted to it.

Remote desktop protocols were designed around Windows. REMOTIX speaks its own protocol over WebTransport, straight to the Linux compositor.

Requirements

What you need.

The server

A Linux machine, physical or virtual: Debian, Ubuntu, Fedora, AlmaLinux, openSUSE or Arch (see Download for the versions). An Intel, AMD or NVIDIA graphics card is recommended; without one REMOTIX encodes in software and declares it.

Whoever connects

Chrome or Edge on Windows, Linux and Android; Firefox on Linux. Nothing to install, no plug-in, no account on our side.

How many users your server can hold depends on its CPU and graphics card: see the sizing guide in the documentation.

FAQ

Questions.

Can I use REMOTIX on Windows servers?

No. REMOTIX serves Linux desktops only. You can connect from Windows, though: any modern browser will do.

Is it really free, even for a company?

Yes. Using REMOTIX costs nothing, at home or at work. A license is needed only to sell it, build it into a product, or sell access to desktops served by it.

Is REMOTIX open source?

The source code is visible, and you can build and modify it for yourself. It is not "open source" in the OSI sense, because selling it and distributing modified copies are reserved.

Does REMOTIX phone home?

No. There is no account, no key and no license check: once installed, REMOTIX works without internet access.

Does it change my system?

No. The installer says what is missing and leaves providing it to you; packages come from the repositories your machine already has, and uninstalling removes what REMOTIX added.
