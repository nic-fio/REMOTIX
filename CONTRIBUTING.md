# Contributing to REMOTIX

Thank you for wanting to help. REMOTIX's source code is public so that you can read it, check it and suggest
how to make it better, but its licence does not allow modified copies (see `LICENSE.md`). So contributions
work like this:

## Open an issue

[Open an issue](https://github.com/nic-fio/REMOTIX/issues/new) for:

- **a bug**: what you did, what you expected, what happened instead. Please include the distribution and
  version, the desktop (GNOME, KDE Plasma, XFCE, LXQt), the graphics card, the browser you connected with,
  and the output of `sh remotix-*.run check` if the problem is about installing;
- **a feature request**: what you would like to do and why. Describing the need is more useful than
  describing the solution;
- **a question** about how REMOTIX works or how to use it.

If you have read the code and know where a problem is, say so in the issue: file and line are welcome.

## Pull requests are not accepted

Pull requests will be closed without being merged, with a request to describe the change in an issue
instead. This is not about the quality of your work: the licence keeps every change in the Author's hands,
and code from outside would make that impossible.

## Commercial use

Using REMOTIX in a commercial setting needs a licence from the Author: write to **remotix@nicfio.it**.
