# REMOTIX (repository root)

One branch (`main`), one directory per distribution: `debian13/`, `ubuntu26.04/` and `fedora45/`. Each directory is self-contained (code, build, tests,
docs, manuals, licences) and has its own `CLAUDE.md` and `PIANO.md`. Nothing is shared between them for now.
Work inside the directory of the distribution you are changing and follow its `CLAUDE.md`; do not move files between them.
