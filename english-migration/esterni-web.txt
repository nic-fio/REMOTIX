# esterni-web.txt — names of the Web platform (and of the protocols the benches speak to browsers)
# that rinomina2.py never renames, whatever the vocabulary says (alt → height made AltLeft HeightLeft).
# One or more names per line; '#' starts a comment.  The tool adds, mechanically, the names each page
# shows to be the platform's (members of event objects, strings compared with .code/.key, attributes
# in setAttribute & co., non-data attribute selectors in CSS) and every aria-* / ariaX name.
# HTML attribute names, CSS properties and values need no list: the tool never renames an attribute
# name other than data-*, and in CSS only selectors, custom properties and @keyframes names are ours.
